# 📋 Product Backlog - Habit Tracker App

This backlog contains all user stories organized by feature and prioritized for development.

---

## 🔴 Login / Registration (High Priority)

### 1. User Registration  
**Description:** Users can create an account using personal details.  
**Labels:** enhancement, priority: high  

### 2. User Login  
**Description:** Users can log in using username and password.  
**Labels:** enhancement, priority: high  

### 3. Login Error Feedback  
**Description:** Users receive an error message for incorrect login attempts.  
**Labels:** enhancement, priority: high  

---

## 🔴 Homepage (High Priority)

### 4. View Welcome Message  
**Description:** Displays personalized welcome message with user name.  
**Labels:** enhancement, priority: high  

### 5. Display Weekly Progress  
**Description:** Shows daily habit progress for tracking consistency.  
**Labels:** enhancement, priority: high  

### 6. View Completed Habits  
**Description:** Displays completed habits separately for tracking achievements.  
**Labels:** enhancement, priority: medium  

---

## 🔴 Menu (High Priority)

### 7. Access Menu Options  
**Description:** Provides navigation to profile, habits, reports, and logout.  
**Labels:** enhancement, priority: high  

### 8. Navigate to Profile  
**Description:** Allows user to open profile page from menu.  
**Labels:** enhancement, priority: medium  

### 9. Navigate to Habits Page  
**Description:** Allows access to manage habits.  
**Labels:** enhancement, priority: high  

### 10. Sign Out  
**Description:** Allows user to securely log out of the app.  
**Labels:** enhancement, priority: high  

---

## 🟡 Profile Page (Medium Priority)

**Labels:** enhancement, priority: medium  

### 12. Edit Personal Information  
**Description:** Allows users to update their profile details.  
**Labels:** enhancement, priority: medium  

### 13. Save Updated Information  
**Description:** Saves profile changes and reflects updates in app.  
**Labels:** enhancement, priority: high

**Labels:** enhancement, priority: low

**Labels:** enhancement, priority: high  

### 16. Delete Habit

**Labels:** enhancement, priority: high

**Description:** Allows assigning colors to habits for better visualization.

**Labels:** enhancement, priority: medium  

### 19. Visualize Completed Habits  
**Description:** Shows charts for completed habits.  
**Labels:** enhancement, priority: medium
